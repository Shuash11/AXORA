# AXORA Hero

This repository currently contains the responsive hero section for the AXORA team landing page.

## Local preview

```bash
python -m http.server 4173 --directory .
```

Open http://127.0.0.1:4173/.

## Checks

```bash
npm test
```

This runs Node-built-in markup and carousel-state tests.

For the static contract, run:

```bash
npm run verify:static
```
